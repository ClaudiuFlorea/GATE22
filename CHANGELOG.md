# Changelog

## 1.0.0

Initial public release.

### Features

- Native macOS terminal with real local zsh sessions
- Saved SSH connections and configurable folders
- Read-only SSH config integration with configurable config path
- Secure saved passwords using macOS Keychain
- Multiple terminal layouts: Single, Columns, Rows, Grid
- Multi-session selection and Close Selected
- Broadcast Input across selected sessions
- Connection search and keyboard shortcuts
- Appearance settings with light/dark application themes and terminal font controls
- Signed and notarized direct distribution
