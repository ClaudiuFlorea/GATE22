# GATE22

GATE22 is a native macOS terminal and SSH client focused on fast local shell access, saved SSH connections, multi-terminal layouts, and broadcast input.

## Download

The first public release will be available from the repository's **Releases** section as a signed and Apple-notarized DMG.

Current release target: **1.0.0**

## Highlights

- Native macOS app
- Real local `zsh` sessions
- Saved SSH connections
- macOS Keychain password storage
- `~/.ssh/config` integration
- Single, Columns, Rows, and Grid terminal views
- Multi-session selection
- Broadcast Input across selected terminals
- Light and dark appearance support
- Apple Developer ID signed and notarized releases

## Updates

Automatic updates will be delivered with Sparkle.

## Source code

GATE22 is currently distributed as closed-source software. This repository is used for public releases, update metadata, release notes, and issue tracking.

## Security

Saved SSH passwords are stored in the macOS Keychain. GATE22 does not store SSH passwords in its connection JSON files.

If you discover a security issue, please avoid posting credentials or other sensitive data in a public issue.
